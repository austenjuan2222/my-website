# 火柴人小寵物 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 首頁右下角可甩鞭的火柴人，點它開個人問答。
**Architecture:** `pet.js` 自建 DOM（canvas＋對話框），Verlet 鞭子在 requestAnimationFrame 中模擬；`PetBrain.answer(q)` 本地關鍵字比對，若有 `PET_AI_ENDPOINT` 先打代理。
**Tech Stack:** 原生 JS、Canvas 2D、Web Audio。
**Spec:** docs/superpowers/specs/2026-11-25-stick-pet-design.md

## Global Constraints
- 不放任何 API 金鑰；不動 rps.html 的 script／firebaseConfig。
- 繁體中文文案；色票沿用首頁 `--accent:#5df0a8`。

## Review Focus
- 手機 390px：寵物與對話框不超出畫面、不蓋住主要按鈕。
- 問題無匹配：回友善預設答案＋快捷按鈕。
- 代理失敗或逾時（>6s）：退回本地答案。
- reduced-motion：鞭子靜止、不出錯。
- 輸入含 HTML：以 textContent 顯示，不注入。
