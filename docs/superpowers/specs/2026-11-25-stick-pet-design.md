# 角落火柴人小寵物＋個人問答 設計（短版）

**意圖**：期末作業網站加一個有記憶點的互動角色。訪客點它就能問「Austen 是誰、網站有哪些工具」等簡單問題。

**目標**：右下角火柴人，手上鞭子有物理擺動（Verlet 繩），點它會甩鞭（啪的音效可關）並開對話框；預設問答不需金鑰、離線可用。
**非目標**：不照抄任何現成作品（Whip Cursor、Lashline 只參考「Verlet 鞭子」這個做法）；這次不放任何 API 金鑰。
**反目標**：擋住頁面內容、手機上誤觸、拖慢首頁。

## Approaches
1. **前端預設問答（選用）**：關鍵字比對本地知識庫，零成本、無金鑰、GitHub Pages 直接上。缺點：只能答預設範圍。
2. **Serverless 代理＋LLM**：Cloudflare Worker 存 Gemini/Claude 金鑰，前端只打 Worker。能自由問答，但要 Austen 申請金鑰，可能有費用。
3. 金鑰直接寫前端：外洩風險，排除。

做法：先上 1，前端留 `window.PET_AI_ENDPOINT` 接口；有設定時先問代理，失敗自動退回預設問答。Worker 範例放 `worker/pet-ai.js`，Austen 同意後再部署。

## 設計
- 檔案：`pet.css`、`pet.js`（獨立、無相依），首頁引入。
- 畫面：固定右下 canvas（約 160×200），點陣綠 `--accent:#5df0a8` 線條，頭會看滑鼠方向；閒置時呼吸。
- 互動：點火柴人＝甩鞭＋開/關對話框；拖曳鞭尾可以自己甩。按 Esc 關閉。
- 問答：快捷按鈕（你是誰／有哪些工具／遊戲／聯絡方式）＋輸入框；答案可附連結。
- 無障礙：火柴人是 `<button aria-label>`；`prefers-reduced-motion` 時不擺動；手機縮小並避開底部。

## v2（2026-11-25 Austen 回饋）
- 桌機（滑鼠裝置）：小鞭走到游標右下方跟著走；整隻 `pointer-events:none`，不擋點擊與選字；身體壓到文字時變淡。滑鼠離開視窗或開對話框時走回右下角。
- 甩鞭：點畫面空白處（非連結/按鈕/輸入框）就朝點擊方向甩，不用拖。快速甩滑鼠鞭子也會跟著甩。
- 對話入口：右下角固定「🤠 問小鞭」按鈕；對話框標頭可切換「跟著滑鼠」開關。
- 觸控裝置與 reduced-motion：維持角落模式（點小鞭開對話、可拖鞭尾）。
- 預設問題按鈕改成自動換行，不再橫向捲動被切掉。
- 音效預設關閉（點畫面就啪會吵），可在對話框開啟。

## v3（2026-11-26 Austen 回饋）
- 甩鞭更大力：鞭子加長（26 節）、後拉過頭再 0.08 秒猛揮、揮出瞬間給鞭身往前的衝量（越靠鞭尾越大）、火花加大並加一圈衝擊波。畫布加大（300×240，左上留空間）避免鞭子被裁掉。
- 往右走改成跳步：身體上下蹦、一腳前踢一腳收膝、空手高舉；往左維持一般走路。
- 點火柴人直接開 AI 問答：跟隨模式也顯示身體上的點擊區。改成「牽繩式」跟隨：游標在小鞭 170px 內時牠站著不動，所以可以直接點到牠（也更不擋字）；點空白處仍是甩鞭。右下角按鈕保留。
